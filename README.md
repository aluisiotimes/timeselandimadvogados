# Site Times, Guedes & Landim Advogados

Layout: modelo 47 (Neon noturno). Site estático em HTML e CSS, sem dependências.

## Estrutura
- `index.html`: página inicial
- `blog/`: lista de artigos e `blog/bpc-loas-quem-tem-direito/` (artigo modelo, em rascunho)
- `bpc/`: página do BPC/LOAS
- `img/`: logos (SVG) e fotos (JPG)
- `vercel.json`, `robots.txt`, `sitemap.xml`

## Como publicar
Copie o conteúdo desta pasta para a raiz do repositório no GitHub. A Vercel publica automaticamente após o commit.
